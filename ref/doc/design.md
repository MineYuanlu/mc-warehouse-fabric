# MC Warehouse 功能设计文档

## 核心功能

### 1. 区域选择
- 玩家通过某种方式（如按键、命令）选择一片 3D 区域
- 区域内所有可交互容器（箱子、木桶、潜影盒等）被标记

### 2. 自动整理
- 按预设规则或玩家自定义规则整理物品
- 支持分类：工具、武器、食物、建筑材料、红石等
- 支持按物品 ID 排序

### 3. 自动化流程
- **自动寻路**：计算到目标容器的路径并移动玩家
- **打开容器**：到达后自动打开容器 GUI
- **移动物品**：将物品按规则放入正确位置
- **关闭容器**：整理完成后自动关闭

## 技术实现要点

### 客户端限制
由于是纯客户端模组，所有操作都通过发送玩家输入/交互包实现：
- 移动：模拟玩家 WASD 移动和视角转动
- 交互：发送 `UseBlock` 或 `UseEntity` 包
- GUI 操作：通过 mixin 拦截容器屏幕，程序化操作物品槽位

### 关键 Mixin 目标
- `Minecraft` - 主循环、屏幕管理
- `MultiPlayerGameMode` - 交互发包
- `AbstractContainerScreen` / `ContainerScreen` - 容器 GUI 操作
- `LocalPlayer` / `Player` - 玩家移动控制

### 配置系统
使用 Fabric API 的配置 API 或自己的 JSON 配置：
- 整理规则定义
- 排除的容器类型
- 区域大小限制
- 整理速度/延迟设置

## 安全与合规

- 所有操作模拟正常玩家行为
- 不修改服务端逻辑
- 不涉及物品复制/生成（纯整理，不改变物品总量）
- 注意服务器反作弊插件可能的检测
