# MC Warehouse 开发文档参考

## 项目简介

MC Warehouse 是一个纯客户端 Fabric 辅助模组，用于帮助玩家自动整理指定区域内的所有容器中的物品，包括自动寻路、打开/关闭箱子等功能。

## 版本兼容性

- **Minecraft**: 26.1.x (目标范围: 26.1 - 26.2)
- **Fabric Loader**: >= 0.18.0
- **Java**: >= 25

## 26.1 关键变化参考

Minecraft 26.1 是模组生态的重大转折点：

### 1. 版本号体系变更
- 从 `1.21.11` 直接跳到 `26.1`，采用年份版本号
- 未来版本将按 `26.2`, `26.3`, `27.1` 等格式发布

### 2. 代码不再混淆 (Unobfuscated)
- Minecraft 26.1 是第一个**不再混淆**的版本
- Mojang 直接使用官方命名（官方映射）
- **Yarn mappings 不再被 Fabric 官方支持**
- 所有旧模组（1.21.11 及更早）至少需要重新编译才能运行

### 3. 构建工具链重大更新

| 工具 | 旧版本 | 26.1 要求 |
|------|--------|-----------|
| Java | 21 | **25** (最低) |
| Gradle | 8.x | **9.4.0** |
| Loom | 1.6 | **1.15** |
| Plugin ID | `fabric-loom` | `net.fabricmc.fabric-loom` |
| IDE (IntelliJ) | 2024.x | **2025.3+** |

### 4. 依赖声明变化
因为不再混淆，不需要 remap：

```gradle
// 旧方式 (1.21.x)
modImplementation "net.fabricmc.fabric-api:fabric-api:VERSION"
modCompileOnly "some:mod:VERSION"

// 新方式 (26.1+)
implementation "net.fabricmc.fabric-api:fabric-api:VERSION"
compileOnly "some:mod:VERSION"
```

同样 `remapJar` 也简化为 `jar`。

### 5. API 重命名
Fabric API 为了匹配官方映射，大量类和方法被重命名：

| 旧名称 (Yarn) | 新名称 (Mojang) |
|---------------|-----------------|
| `ItemGroupEvents` | `CreativeModeTabEvents` |
| `ColorProviderRegistry` | `BlockColorRegistry` |
| `FluidRenderHandler` | `FluidModel` |

完整重命名列表可参考 [Fabric API 26.1 Porting Guide](https://docs.fabricmc.net/develop/porting/fabric-api)

### 6. Fabric API 结构变化
- `fabric` mod ID 被移除（已废弃 3 年以上），必须使用 `fabric-api`
- Model Loading API 和 Renderer/Indigo 模块可能初始版本不可用
- 新增了 `BlockColorRegistry` 替代旧的 `ColorProviderRegistry`

## 开发注意事项

1. **纯客户端模组**：`fabric.mod.json` 中设置 `"environment": "client"`
2. **入口点**：使用 `client` entrypoint 而不是 `main`
3. **Mixin**：如有需要，在 `src/client/resources/` 下放置 mixin 配置
4. **Java 25 特性**：可以合理使用 Java 25 的新特性（如模式匹配增强等）
